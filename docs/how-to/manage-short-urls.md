# Manage short URLs

SIMVA can register a study in [Shlink](https://shlink.io) and hand participants a short URL,
so a printed poster or a slide can point at the study instead of at a 120 character query
string.

```bash
export SIMVA_URL=https://simva.example.edu
export TOKEN='...'
export SIMLET_ID=42
```

## Create one

Let SIMVA pick a short code:

```bash
curl -s -X POST "$SIMVA_URL/simlets/$SIMLET_ID/shlink" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"length": 6}' | jq
```

Or choose the code yourself — useful when the short URL has to be memorable or has to match
something already printed:

```bash
curl -s -X POST "$SIMVA_URL/simlets/$SIMLET_ID/shlink" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"customSlug": "study-2026"}' | jq
```

```json
{
  "simlet_id": 42,
  "shlink_id": 3,
  "short_url": "https://sho.rt/study-2026",
  "long_url": "https://simva.example.edu/simlets/42"
}
```

## Read, change, remove

```bash
curl -s "$SIMVA_URL/simlets/$SIMLET_ID/shlink" -H "Authorization: Bearer $TOKEN" | jq

curl -s -X PATCH "$SIMVA_URL/simlets/$SIMLET_ID/shlink" \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"customSlug": "study-2026-final"}' | jq

curl -s -X DELETE "$SIMVA_URL/simlets/$SIMLET_ID/shlink" -H "Authorization: Bearer $TOKEN"
```

## Configure the Shlink server

```bash
SHLINK_SERVER_HOST=shlink.example.edu
SHLINK_SERVER_API_KEY=...
SHLINK_PROTOCOL=https
```

`src/lib/config.ts` builds `config.shlink.url` from these, omitting the port when it is 80,
443 or 8080.

## Gotchas

- **One short URL per simlet.** A second `POST` is rejected rather than replacing the first.
- **Short URL rows are not soft deleted.** Every other table in the schema soft deletes;
  `SimletShlinks` was explicitly exempted because soft-deleting broke URL resolution. See
  [ADR-0010](../explanation/decisions/0010-soft-delete-and-the-admin-bypass.md).
- **The redirect target is generated by SIMVA.** If you need to change where the short URL
  points, change the simlet's public URL configuration, not the Shlink record.
